# README に書かない読み込ませ方

## 扱うこと

README のセットアップと使い方を書くとき、スキルを会話の最初に読み込ませる設定を書くか

## 答え方と理由

### 0. 判断全体

実装の判断。README の章と書かないものは、この判断では答えない（→ [README](readme-contents.md)）。

- （根拠）設計文書の 3-3 は、3-4 の基準を人が読む文書にも当てはめると決め、3-4 は、指名し忘れたときの備えを導入先に置くと決めているが、README のセットアップに読み込ませる設定を書くかは書いていない。（決定日：2026-11-20）

### 1. 会話の最初に読み込ませる設定は、README に書かない

スキルを会話の最初に読み込ませる設定（`AGENTS.md` や `CLAUDE.md` に書く1文・hooks など）を、README のセットアップと使い方に書かない。すべての作業に当てはめるロジックスキルでも、使い方は「主にアプリケーションスキルから呼ばれる」のまま書く。どのスキルをいつ読ませるかは、導入先が決める（→ [description](description.md) の答え方5）。

1. （原因）AIエージェントの動かし方の中核判断の README に、「会話の最初に読み込ませる」の小見出しを立て、`AGENTS.md` に読み込ませる1文を書く手順を置いていた。使い方も「セットアップの1文で会話の最初に読み込まれる」と書いていた。指示者に、スキルの担当範囲を超えていると指摘されて消した。（発生日：2026-11-20）

# README に書く Codex での使い方

## 扱うこと

README を書くとき、Claude Code のほかに Codex での使い方を書くか、書くならどの章にどう書くか

## 答え方と理由

### 0. 判断全体

実装の判断。README の章と書かないものは、この判断では答えない（→ [README](readme-contents.md)）。

- （根拠）設計文書の 3-3 は README の章と書くことを決めているが、どのAIエージェントでの使い方を書くかは書いていない。作成者が、README に Codex についても書くよう指示した。（決定日：2026-11-25）

### 1. Claude Code でしか使えない道具に頼るスキルを除き、Codex での使い方も書く

README には、Claude Code での使い方だけを書かない。Codex での使い方も書く。ただし、Claude Code でしか使えない道具（Claude in Chrome など）に頼るスキルの README には、Codex での使い方を書かない。

1. （原因）README の「必要なもの」に Claude Code だけを書いていて、作成者に、Codex でも使えると指摘された。（発生日：2026-11-25）
2. （根拠）作成者が、Claude Code でしか使えない道具に頼るスキルには書かないと決めた。（決定日：2026-11-25）

### 2. 名前は「Codex」と書く

名前は「Codex」と書く。「Codex アプリ」と書かない。

1. （根拠）作成者が、「Codex アプリ」の表記を「Codex」にすると決めた。（決定日：2026-11-25）

### 3. 章ごとに、次の形で書く

| 章 | 書くこと |
|---|---|
| `## 必要なもの` | 1行に「Claude Code か Codex」と書き、それぞれの公式の文書へのリンクを付ける |
| `## インストール` | Claude Code でクローンするコマンドを1つ書き、Codex では `~/.claude/skills/` を `~/.agents/skills/` に替えると書く。プロジェクトだけで使うときは、Codex では `<プロジェクト>/.agents/skills/` と書き添える |
| `## セットアップ` | コマンドに `~/.claude/skills/` があれば、Codex では `~/.agents/skills/` に替えると書く |
| `## 使い方` | Codex では、例の `/` を `$` に替えて指名すると書く |

コマンドと頼み方の例は、Claude Code の形で1つだけ書く。Codex の分を別に並べない。

1. （原因）作成者が Codex アプリで `$` を付けて指名し、スキルを呼び出せた。（発生日：2026-11-25）
2. （知見）Codex は、スキルを `~/.agents/skills/` と `<プロジェクト>/.agents/skills/` から読む。（出典：なし）

### 4. どちらのAIエージェントにも当てはまる文では、「Claude」と書かず「AIエージェント」と書く

「Claude に接続した」「Claude に渡さない」「Claude Code を起動するフォルダ」のように、どちらのAIエージェントにも当てはまる文では、「Claude」「Claude Code」と書かない。「AIエージェント」と書く。

1. （根拠）作成者が、「Claude」を「AIエージェント」に替えると決めた。（決定日：2026-11-25）

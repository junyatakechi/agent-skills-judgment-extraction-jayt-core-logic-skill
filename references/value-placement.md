# 値の置き場所

## 扱うこと

値を書くとき、ロジックスキル・取り決めファイル・`.env`・材料のどこに置くか

## 答え方と理由

### 0. 判断全体

設計文書を写す判断。

- （知見）設計文書の 1-4・1-5・3-1 を写した。（出典：人の判断を切り出すAIスキルの設計_v2.1.1 の1-4・1-5・3-1@2026-11-13）

### 1. 誰が決めた値かで、置き場所を決める

置き場所は、その値を誰が決めたかで分ける。core-logic か generic-logic かでは分けない。

| 値の種類 | 誰で決まるか | 例 | 正（大元） |
|---|---|---|---|
| 判断定数 | ロジックスキルの作成者 | 停滞判断の窓 14日 | 判断ファイルの「判断定数」の表。道具はその表を実行時に読む |
| 環境の仕様 | 環境の提供元 | Web APIのレート制限 | 道具のコードの定数 |
| 数学・物理の定数 | 誰が決めても同じ | t分布の表 | 道具のコード |
| 導入先の環境（IDとトークン） | スキルを入れた個人や組織 | DBのID・トークン・カレンダーのID | プロジェクトのフォルダ直下の `.env` |
| 導入先の環境の取り決め | 導入先や判断の対象の運用 | 読むDBと列・記録の書き方・本人の語の一覧 | アプリケーションスキルの取り決めファイル（`conventions/`） |
| 対象の値（属性・記録） | 判断の対象 | 目標・毎日の体重 | 導入先のデータ（NotionのDB・カレンダー・プロジェクトのフォルダに置いたJSONなど）。どこにあるかは取り決めファイルに書く。アプリケーションスキルが写しを材料として渡す |

外から受け取る値（導入先の環境・導入先の環境の取り決め・対象の値）を、ロジックスキルに書かない。

1. （根拠）外から受け取る値を書くと、その導入先や対象の専用になり、そのまま渡せなくなる。（決定日：記録なし）

### 2. 似た値は、作成者が決めた部分があるかで見分ける

判断定数と対象の値は、どちらも人が決めることがある。見分けるのは、誰が決めたか。境目にある値は、作成者が決めた部分があるかで決める。

1. 記録なし

### 3. 多くのスキルが import する道具は、表を読まない

多くのスキルが読み込むたびに import する道具は、表を読まない。判断定数があるときは、コードに定数として置き、判断ファイルの「判断定数」の表に写しとして残す。表の上に、正がコードの定数であることを書く。判断を聞かれたときだけ動く道具は、表を読んでよい。値が見つからなければ、どの表のどの名前が無いかを示して止まる。

1. （根拠）表の書き損じが1つあるだけで、その道具を使うすべてのスキルが止まる。人が判断定数を探すのは判断ファイルなので、表から消すと、判断定数があることに気づけなくなる。（決定日：記録なし）

### 4. 外から受け取る値は、3つの置き場に分ける

| 置き場 | 置くもの | 例 |
|---|---|---|
| 導入先のデータ | 対象の値（属性・記録）。対象について読まれる値 | NotionのDBの体重記録・カレンダーの食事の予定・プロジェクトのフォルダに置いたJSONの目標体重 |
| アプリケーションスキルの取り決めファイル（`conventions/`） | 導入先の決まり（定数や対応付け）。何がどこにあり、どう書かれているか | 読むDBと列・食事の記録の書き方・本人の語の一覧（「おやつ」は間食） |
| プロジェクトのフォルダ直下の `.env` | IDとトークンの実値 | DBのURL・カレンダーのID・トークン |

データと取り決めは、決まりかどうかで見分ける。本人の語の一覧は対応付けなので取り決めファイル、目標体重は本人について読まれる値なので導入先のデータに置く。取り決めファイルの定数は導入先の定数で、判断定数とは違う。プロジェクトのフォルダ直下の `.env` は、プロジェクトのスキルで共有し、キーの中身は各スキルの `.env.example` が持つ。同じプロジェクトのフォルダに置くときも、`.env` とデータのファイルを分ける。

1. （根拠）語の一覧は「この語は間食」という対応付けで、取り決めファイルは定数や対応付けなどの決まりを書く場所である。目標体重は、体重記録・食事記録と同じく、導入先のデータから取ってくる値である。記録の書き方の印や列名は導入先が決め、判断定数は作成者が決める。`.env` は、スキルに書けないIDとトークンの置き場で、対象の値の置き場ではない。（決定日：2026-11-13）

### 5. 本人の語の一覧は、材料で渡し、ロジックスキルが当てはめる

本人の語の一覧は、材料で渡し、ロジックスキルが当てはめる。アプリケーションスキルが語で記録を判定し、判定した印を渡さない。

1. （根拠）何をどの語でまとめるかが判断で、判断はロジックスキルが持つ。（決定日：2026-11-13）
2. （原因）ダイエット進捗の評価アプリが、記録ごとに `種類`・`入手元`・`いつもの枠` を判定して渡していて、何を間食・外食・普段の食事とするかの判断が、アプリのコードの中にあった。（発生日：2026-11-10）
